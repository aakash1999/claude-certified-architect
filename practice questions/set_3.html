Scenario Brief

Ledgerline moves money: payment infrastructure for 2,300 business customers, where every merge is audited and every bug has a dollar sign on it. Its 60 engineers open ~90 pull requests a week into the ledgerline-core monorepo. Argus is the CI reviewer — Claude Code running headless in the pipeline on every PR for automated code review and test generation, plus a nightly dependency audit across 140 service repos via the Message Batches API. Targets: ≥95% of posted findings actionable (currently 84%), review turnaround under 10 minutes, zero missed security-critical defects.
