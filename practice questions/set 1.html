Scenario Brief

NimbusCart is a mid-sized online retailer running ~3,400 support conversations a day through Aria, a resolution agent built on the Agent SDK. Core MCP tools: get_customer, lookup_order, process_refund, escalate_to_human; issue_store_credit was added last quarter, and the tool list has crept to 18. Refund policy: auto-approved ≤ $150 · $150–$500 requires identity verification · > $500 goes to a human. Target: 80% first-contact resolution (currently 71%).
